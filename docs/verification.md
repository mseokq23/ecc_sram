# 검증 기록

모델: 공식 PDK 260820(`05cmos_mosfet_corner.lib` TT/SS/FF/SF/FS, nmos4/pmos4), ngspice-42.
Vt 불일치는 PDK에 모델이 없어 Pelgrom 계수 A_VT = 12(N) / 15(P) mV·µm를 가정했다.
각 단계 끝의 **판단**은 그 단계까지 본 것으로 이 주제가 칩으로 동작할지에 대한 결론이다.

## 1. 개발환경 (2026-11-03)

- Codespaces 이미지 IIC-OSIC-TOOLS 2026.10 기준으로 구성. 로컬(Ubuntu 24.04, magic 8.3.105, klayout 0.28.16, ngspice-42, yosys 0.33, iverilog 12)에서도 같은 흐름이 돈다
- `smoke-test.sh` 19항목 중 18 통과. 빠진 1개는 noVNC 데스크톱(로컬에는 없음)
- 킷: GoodKook/ETRI-0.5um-CMOS-MPW-Std-Cell-DK 4b332a7(2026-11-02)

`sim/cell/retention_time.py`: VDDA를 1 ms에 걸쳐 V_hold로 내리고 100 s 둔 뒤 1 ms에 걸쳐 5 V로 올림, TT 27 °C. 셀은 Q = 1을 저장하고, 쓰기 드라이버가 Q 쪽 BL = 0, QB 쪽 BLB = VDDA로 붙잡는 가장 나쁜 경우.

| Vt 기울기 (Q = 0 쪽) | DC 보존 전압 | 데이터를 잃는 V_hold | 잃기까지 걸린 시간 |
|---|---|---|---|
| 0 σ | 0.387 V | 0.35 V (0.30 V 이하는 아래 셋째 줄) | 1.38 s |
| 1.5 σ | 0.417 V | 0.40 V 이하 | 0.72–1.74 s |
| 3 σ | 0.447 V | 0.40 V 이하 | 0.59–0.85 s |

- DC 보존 전압보다 높으면 100 s 동안 그대로다. 낮으면 1–2 s 안에 Q와 QB가 뒤바뀐다
- 처음 수백 ms 동안은 저장된 1이 새 VDDA보다 높은 채 남아 누설로만 천천히 내려간다. 그래서 짧은 유지(µs–ms)로는 보존 전압보다 훨씬 낮은 VDDA에서도 데이터가 남아 보인다
- 0.30 V 이하에서는 두 노드가 거의 같은 전압(차이 약 10 mV)으로 모이고, 5 V로 올릴 때 셀이 원래 기우는 값으로 정해진다. 기울기 0인 셀은 이때 1로 돌아왔다. 한 패턴만 보면 실패를 놓친다

**판단**: 5 V 동작은 모든 코너에서 여유가 크다(쓰기 트립 1.66 V 이상, SNM 1.26 V 이상). 물리 결함 실험의 두 손잡이가 모두 측정 가능한 범위에 있다. 보존 실패는 VDDA 0.34–0.42 V 근처에서 셀마다 퍼져 나오고(10 s 이상 유지 필요), 읽기 실패는 VDDA 약 1.4 V에서 나온다. 측정 계획은 [spec.md](spec.md)의 측정 계획 3에 반영했다.

## 3. 셀·어레이 레이아웃

`gen/sram8t.py`가 셀과 15 × 8 어레이를 Magic으로 그린다. 홀수 행은 위아래로 뒤집어 VSS 레일을 나눠 쓴다. 왼쪽 끝에 워드라인 30개의 poly → metal3 접속, 오른쪽에 VDDA·VSS metal2 버스, 아래쪽에 BL·BLB·RBL metal2 핀.

| 검사 | 셀(1 × 1, 가장자리 포함) | 어레이 15 × 8 |
|---|---|---|
| Magic DRC | 0 | 0 |
| KLayout DRC (킷 덱 v1.1) | 0 | 0 |
| LVS (Netgen) | 일치 | 일치, 960 소자 · 416 넷 |
| Calibre 전용 73규칙 (`calibre_rules.py`) | 0 | 0 |
| 규칙 7–12, 문서 값 (`metal_rules.py`) | 0 | 0 |
| 안테나 (`antenna_rules.py`) | 0 | 0 |

고친 것: via1 옆 metal1이 Magic GDS 출력에서 0.05 µm 당겨져 0.6 µm 조각이 생기던 것(8.MET1.W) → via 둘레에 metal1을 1λ 더 둠. 셀 혼자일 때 접점 없는 워드라인 poly(3.PL1.bad1) → 셀도 어레이 가장자리째로 그림.

## 4. 어레이 후모의

`sim/post/array_post.py`: 그린 어레이를 Magic으로 추출(소자 + 기생 C, C × 1.5)하고 컬럼 회로는 6절에서 그린 것과 같은 회로도(크기 포함)로 붙였다. VSS는 0 V. 15행 모두에 체커보드와 반전을 쓰고 모두 읽어 8비트씩 비교.

| 경우 | 읽은 비트 | 틀린 비트 |
|---|---|---|
| TT 27 °C 5 V | 240 | 0 |
| SS 125 °C 4.5 V | 240 | 0 |
| FF 0 °C 5.5 V | 240 | 0 |
| SF 27 °C 5 V | 240 | 0 |
| FS 27 °C 5 V | 240 | 0 |
| TT 27 °C, VDDA 2.0 V | 240 | 0 |
| VDDA를 0.6 V로 2 µs 내렸다 복구 | 120 | 0 |
| VDDA를 0.2 V로 2 µs 내렸다 복구 | 120 | 0 |

마지막 두 경우는 VDDA를 내렸다 올려도 쓰기 드라이버와 어레이가 데이터를 건드리지 않는지 보는 것이다. 2 µs는 보존 시험으로는 너무 짧다(2절).

Magic 추출 계수는 이 킷에서 AMI 0.5 µm 값이라 ETRI 표와 다르다. 그래서 C를 1.5배 해서 돌렸다.

**판단**: 그린 어레이가 모든 코너에서 쓰고 읽힌다. 남은 위험은 컬럼 회로를 아직 그리지 않은 것이다(다음 단계).

## 6. 컬럼 회로와 SRAM 매크로

`gen/colper.py`가 어레이 아래에 열마다 컬럼 회로를 그리고 어레이와 합쳐 `sram_macro`(176.1 × 498.3 µm)를 만든다.

- 위(VDD): RBL → 센스 인버터 → SB → 출력 인버터 → SENSE. keeper(게이트 SB), 프리차지(게이트 PRE_N)
- 아래(VDDA): WD → BLB 드라이버 → BLB → BL 드라이버 → BL
- 인버터는 손가락 2개씩이고 소스를 이웃 열과 나눠 써서 18 µm 폭에 들어간다. 두 N-well(VDD, VDDA) 간격 13.8 µm(다른 전위 규칙 4.0 µm)

| 검사 | 결과 |
|---|---|
| Magic DRC | 0 |
| KLayout DRC (킷 덱) | 0 |
| LVS | 일치, 1,040 소자(병렬 손가락 64쌍 합침) · 442 넷 |
| Calibre 전용 73규칙, 규칙 7–12, 안테나 | 0 |

고친 것: g1–g2를 잇는 폴리 접점이 옆 게이트 폴리와 2λ였다(Magic 5.5.b, 4λ 필요). g2를 2λ 옮겨 접점이 g2를 감싸게 했다.

회로에서 바뀐 것(2절 모의는 바뀐 회로로 다시 돌린 값):
- 쓰기 드라이버: WD → WDB → BL 대신 BLB = not WD, BL = not BLB. WDB 인버터가 열 폭에 들어가지 않아서다. 쓰기 지연·트립은 그대로
- 센스·출력 인버터: 손가락 2개라 P 9.0 N 3.6(비율 2.5는 그대로, 문턱 같음). RBL 부하가 늘어 읽기 최대 1.17 → 1.23 ns. 읽기 Vmin은 그대로

매크로 후모의(`array_post.py --macro`): 매크로 전체를 Magic으로 추출(C × 1.5)해 핀에서 구동한다. WWL/RWL은 1 kΩ을 거쳐, SENSE마다 100 fF(제어 블록까지 배선 몫).

| 경우 | 읽은 비트 | 틀린 비트 |
|---|---|---|
| TT 27 °C 5 V | 240 | 0 |
| SS 125 °C 4.5 V | 240 | 0 |
| FF 0 °C 5.5 V | 240 | 0 |
| SF 27 °C 5 V | 240 | 0 |
| FS 27 °C 5 V | 240 | 0 |
| TT 27 °C, VDDA 2.0 V | 240 | 0 |
| VDDA를 0.6 V로 2 µs 내렸다 복구 | 120 | 0 |
| VDDA를 0.2 V로 2 µs 내렸다 복구 | 120 | 0 |

테스트벤치 수정: 4절의 처음 결과는 어레이의 VSS가 접지에 묶이지 않은 채(NMOS 바디 다이오드로 0 V 근처에 떠 있음) 돌린 것이었다. VSS를 0 V에 묶고 컬럼 회로를 그린 것과 같게 바꿔 4절을 다시 돌렸다. 결과(오류 0)는 같았다.

**판단**: 그린 SRAM 매크로(어레이 + 컬럼 회로)가 핀에서 모든 코너로 쓰고 읽힌다. SRAM 쪽 블록은 이것으로 다 그렸다. 남은 것은 VDDA 디커플링과 칩 조립이다.

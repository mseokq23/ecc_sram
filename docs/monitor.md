# 신뢰성 모니터: 설계안과 검토

2026-11-03 최종 GDS는 코어 위쪽(x 470–1458, y 1080–1458 µm, 약 0.37 mm², 코어 창의 36 %)이 비어 있었다. 킷 덱과 ETRI Calibre 덱 모두 밀도 규칙이 없어 더미 채움은 규칙상 필요 없다. 이 자리에 칩 주제(ECC가 실제 물리 결함을 고치고 검출하는지 측정)를 더 완성하는 회로를 넣었다. 이 문서는 그 설계안, 실현 가능성과 완성도 검토, 측정 계획이다. 검증 수치는 [verification.md](verification.md) 12절.

## 1. 주제에서 빠져 있던 것

1. **다이의 공정 위치를 모른다.** 보존 전압 모의값은 코너마다 크게 다르다(TT 0.373, SS 0.410, FF 0.327, SF 0.254, FS 0.485 V). 칩에서 잰 보존 전압·읽기 Vmin·쓰기 Vmin을 모의와 맞춰 보려면 그 다이가 어느 코너 쪽인지 알아야 한다
2. **보존 실패는 미리 알 수 없다.** 셀은 VDDA를 낮춘 채 1–2 s를 넘기면 값을 잃고, 잃은 뒤에야 원시 보기로 보인다. 같은 칩 안에서 셀보다 먼저, 같은 원리로 실패하는 기준이 없다
3. ECC는 고치고 검출하는 장치다. 신뢰성 설계에서는 여기에 실패가 다가오는 것을 알리는 감시 회로(카나리)를 붙인다. 이 칩은 고치기·검출하기만 보여 준다

## 2. 후보

| 후보 | 새 핀 | 주제와의 관계 | 판단 |
|---|---|---|---|
| 더미 금속 채움 | 0 | 없음 | 규칙상 필요 없음 |
| SRAM 행 추가 | 주소 1 이상 | 같은 실험의 비트 수만 늘어남 | 28핀이 모두 쓰여 핀이 없음, 제어 블록 재설계 |
| **카나리 래치 사다리 (VDDA)** | 0 | 보존 실패의 조기 경보, 셀과 같은 원리 | **채택** |
| **링 오실레이터 뱅크 + 분주기** | 0 | 다이의 공정 코너 → 모의와 측정 비교 | **채택** (pdkv 칩의 RO 뱅크 재사용) |
| 온도 센서(PNP, 다이오드) | 아날로그 1 이상 | 온도 보정 | 남는 핀 없음, ADC 필요 |

채택한 둘은 새 핀 없이 기존 출력(DOUT)으로 읽는다. 읽기 모드 11(원시 보기)의 FI_POS 두 비트를 보기 선택으로 쓴다.

## 3. 설계

### 3.1 보기 (FI_MODE = 11, WE = 0)

| FI_POS[2:1] | 보기 | DOUT | 함께 하는 일 |
|---|---|---|---|
| 00 | 원시 보기 (기존) | FI_POS0 = 1: {R7, R6, R5, R3}, 0: {R4, R2, R1, R0} | |
| 01 | 카나리 보기 | FI_POS0 = 1: CAN[7:4], 0: CAN[3:0] (1 = 잃음) | 읽기 게이트 켬(CRD_N = 0) |
| 10 | 카나리 세트 | 카나리 보기와 같음 | CLK = 1인 동안 CSET = 1: 8개 모두 세트 |
| 11 | RO 보기 | {0, 0, 0, RO_DIV} | DIN[1:0]로 링 선택: 00 INV, 01 NAND, 10 NOR, 11 없음 |

- SEC/DED는 모든 읽기 모드에서 그 주소 워드의 판정 그대로
- 바뀐 점: 원시 보기는 FI_POS[2:1] = 00이어야 한다(전에는 무시)
- 쓰기(WE = 1)와 모드 00–10은 그대로. RO는 RO 보기에서만, 카나리 세트는 세트 보기에서만 움직인다

### 3.2 카나리 래치 (`gen/canary.py`, 270 × 76.8 µm)

래치 8개를 셀 전원 VDDA에 둔다. 한쪽 인버터(CINV)는 약한 PMOS P1(W 1.8 µm, L 큼)과 넓은 NMOS N1이고, 다른 쪽은 킷 NOR2X1(B = CSET)이다. 세트 상태(A = 1)는 P1의 문턱 아래 전류가 N1의 꺼진 누설을 이겨야 유지된다. VDDA를 내리면 P1이 먼저 지고, 래치는 반대 상태로 넘어가 VDDA를 되돌려도 그대로다. 셀의 보존 실패(PU 대 PD·PG 누설)와 같은 싸움을 더 크게 기울인 것이라 코너를 따라 함께 움직인다.

|---|---|---|---|---|---|
| 0 | 2.4 | 3.6 | 0.428 | 0.303 (SF) – 0.553 (FS) | 10.1 |
| 1 | 4.8 | 3.6 | 0.443 | 0.320 – 0.571 | 9.1 |
| 2 | 4.8 | 6.0 | 0.465 | 0.341 – 0.595 | 6.7 |
| 3 | 9.6 | 6.0 | 0.487 | 0.361 – 0.616 | 7.2 |
| 4 | 9.6 | 9.0 | 0.506 | 0.380 – 0.635 | 6.3 |
| 5 | 14.4 | 9.0 | 0.520 | 0.392 – 0.649 | 4.9 |
| 6 | 19.2 | 12.0 | 0.541 | 0.414 – 0.672 | 4.3 |
| 7 | 30.0 | 18.0 | 0.575 | 0.447 – 0.707 | 3.9 |
| 셀(가장 나쁜 조건) | | | 0.387 | 0.273 (SF) – 0.507 (FS) | 14.7 |

- C0은 모든 코너에서 셀의 가장 나쁜 보존 전압보다 28–64 mV 높고, 사다리는 그 위로 약 150 mV에 걸친다
- 읽기 게이트는 NOR2X1(A = 래치, B = CRD_N, VDD). CRD_N = 1이면 직렬 PMOS가 꺼져 VDDA를 낮춘 동안 VDD 전류가 흐르지 않는다
- 래치 행(VDDA)과 읽기 행(VDD)은 N-well을 4.0 µm 넘게 떼었다(전위가 다른 웰 간격)

### 3.3 링 오실레이터 뱅크 (`gen/robank.py`, 345.1 × 198.9 µm)와 분주기 (`ctrl/ro_div`, 219.6 × 150.9 µm)

- 31단 링 3개: INV(INVX1), NAND(NAND2X1, NMOS 직렬), NOR(NOR2X1, PMOS 직렬). 0단은 NAND2X1(B = 활성)이라 멈춘 링은 탭이 1이다. 탭은 INVX1 → INVX4로 분주기에 간다. INV 링은 전체 속도(SS–FF), NAND/NOR 비는 N/P 기울기(SF, FS)를 가른다
- pdkv 칩의 RO 뱅크 배치·배선을 그대로 쓰되(배선 RO와 저항 RO는 뺌) NAND·NOR 단의 B 입력만 바꿨다: VDD·VSS에 묶지 않고 활성 신호(NOR는 인버터 XE2를 거친 반전)에서 받는다. 도는 동안의 전압은 같고(VDD/VSS), 전원 넷에 게이트가 없어 안테나 규칙의 전원 넷 비가 생기지 않는다
- 분주기: 세 탭의 AND를 토글 8단(DFFSR)으로 256분주, RO_DIV = not q7. 활성이 하나도 없으면 리셋(RO_DIV = 1). DFFSR의 S 입력은 합성기가 VDD에 묶는 대신 rst_n | ~rst_n(INVX1, OR2X1)에서 받는다
- 제어 블록이 RO_EN[2:0]을 내고 RO_DIV를 DOUT0으로 보낸다. 측정은 DOUT0의 주파수 × 256

### 3.4 배치 (`chip/assemble.py`)

```
 y 1440–1448   N 패드 출력 DED·SEC·DOUT3 (metal3, x 1435–1441의 metal2로 올라옴)
 y 1418–1426   FI_POS 띠 (제어 블록 핀에서 카나리 왼쪽으로 곧게 올라옴)
 y 1158.2–     카나리(x 554)   RO 뱅크(x 829)   분주기(x 1184)
 y 1138–1151   VDDA 띠(metal3), VSS 띠(metal3), VDD 띠(metal1)
 y 1086–1134   위 채널 13트랙(metal3, 4 µm 간격): 제어 블록 출력·모니터 핀 ↔ 블록 포트
 y 1080        제어 블록 위쪽 핀 23개
```

- 채널 트랙은 제약 있는 left-edge로 정한다(`channel_tracks()`): 위 포트와 아래 핀이 3 µm 안에서 겹치면 위 포트의 트랙을 위로. CAN7은 블록 포트를 제어 블록 핀 바로 위에 두어 곧은 선
- 전원: VDD는 제어 블록 vdd 스파인을 위로 늘인 metal1, VSS는 제어 블록 gnd 스파인과 매크로 VSS 버스에서, VDDA는 매크로 VDDA 버스에서. 매크로 버스가 채널을 지나는 x 1226–1235에는 블록 핀을 두지 않았다(분주기의 TAP 핀은 그 서쪽, EN·DIV 핀은 동쪽)
- 제어 블록을 다시 배치·배선하면서 qflow가 핀 줄 바깥으로 지나가는 배선 두 개를 만들었다(오른쪽 WWL3이 WWL2 핀을 돌아감, 아래쪽 한 넷이 WD4·WD5 핀 밑을 지남). 조립이 이것을 찾아 WWL2는 핀에서 metal2로, WD4·WD5는 핀에서 metal3로 넘어간다. 워드라인 트랙은 넓어진 gnd 스파인을 피해 x 968부터

## 4. 검토

### 4.1 실현 가능성

| 항목 | 결과 |
|---|---|
| 면적 | 빈 곳 안에 들어감. 블록 x 554–1404, y 1158–1357 + 채널·띠 y 1086–1151. 위쪽 띠와 패드 사이 여유 그대로 |
| 핀 | 추가 없음(28핀 그대로) |
| 제어 블록 | 합성 347 → 375셀, 489.6 × 481.05 → 495.9 × 520.05 µm, 핀 70 → 84. 시험 121,616 → 160,039회 비교 통과 |
| 전력 | 카나리: VDDA 누설(pA–nA). RO: 링 하나가 돌 때만 6.7–10.8 mW(코너·온도), RO 보기 밖에서는 정지 |
| 규칙 검사 | 칩 공식 DRC 0, Calibre 전용 0, 규칙 7–12 코어 0, 안테나 0, 코어 LVS 일치(4,198 소자), 제출 GDS 검사 통과 |
| 일정 | 2026-11-06 완료. 4차 DB 마감(12/7) 전 |

### 4.2 완성도

- 측정 → 모의 연결: RO 세 주파수로 다이의 코너를 정하고, 그 코너의 모의값(보존 전압, 읽기·쓰기 Vmin)과 측정값을 비교한다
- 고치기·검출하기에 예측이 더해진다: 카나리 사다리가 VDDA를 내릴 때 셀보다 먼저(셀의 보존 전압보다 약 30–270 mV 위에서) 차례로 넘어가므로, 어레이 실패 지도(원시 보기)와 같은 다이에서 "카나리 몇 개가 넘어갔을 때 셀이 실패하기 시작하는가"를 잰다
- 쓰기·읽기·결함 주입과 모든 기존 동작은 그대로(모드 표에서 원시 보기만 FI_POS[2:1] = 00 조건이 붙음)

### 4.3 위험과 대책

| 위험 | 대책 |
|---|---|
| 카나리의 전원 켤 때 상태가 정해지지 않음 | 쓰기 전에 반드시 세트 보기로 세트(두 반쪽, CLK = 1 100 ns 이상) |
| VDDA를 낮춘 채 카나리 보기를 하면 거짓 1, VDD 전류 0.1–0.5 mA | 카나리 보기는 VDDA를 VDD로 되돌린 뒤에만 |
| 카나리가 넘어가는 데 시간이 걸림(보존 전압 30 mV 아래에서 1.6–8.1 s) | 한 단계 유지 30 s 이상(셀 실험의 10 s보다 길게) |
| 절대 전압은 누설 모델에 달림 | 사다리의 순서와 셀과의 상대 위치를 같은 다이의 어레이 지도로 맞춘다 |
| 가장 약한 셀은 C0보다 먼저 실패할 수 있음(셀 σ 14.7 mV, C0 σ 10 mV, 공칭값 차 41 mV) | C0–C7은 경보 문턱이 아니라 VDDA에 따른 추세. 실패 지도와 함께 본다 |
| RO 스위칭 잡음 | RO 보기에서만 돈다. 보존·Vmin 실험 중에는 RO 보기를 쓰지 않는다 |
| RO 주파수가 높음(44–92 MHz, 후모의) | DOUT0에는 256분주(174–358 kHz)만 나온다 |

## 5. 측정 계획 (spec.md 측정 계획 5, 6)

1. RO: FI_MODE = 11, FI_POS = 11x, WE = 0, DIN[1:0] = 00/01/10에서 DOUT0 주파수를 재고 × 256. 모의 표(verification.md 12절)와 비교해 코너를 정한다
2. 카나리:
   1. 5 V에서 세트: 읽기 두 번(FI_POS = 100, 101)
   2. 확인: 카나리 보기(FI_POS = 010, 011) → 0000, 0000
   3. VDDA(와 VDDW)를 V_hold로 내려 30 s 이상 두고 5 V로 되돌림
   4. 카나리 보기: 넘어간 카나리 = 1. 이어서 원시 보기로 어레이 실패 지도(값과 반전 두 패턴, 측정 계획 3)
   5. V_hold를 0.70 V부터 10 mV씩 내리며 반복. 모의(TT)로는 C7(0.575 V)부터 C0(0.428 V)까지 차례로 넘어가고, 그 아래 0.34–0.42 V에서 셀이 실패하기 시작한다

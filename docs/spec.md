# 사양

## 구성

```
            ┌──── VDD 5 V ─────────────────────────┐        ┌──────── SRAM 매크로 ─────────────────────┐
 입력 15 ─▶ │ ecc_fi_ctrl (표준셀, qflow)           │        │ 8T 어레이 15행 × 8열        (VDDA)        │
            │  부호기, 결함 마스크, 행 해독,         │──────▶ │  WWL[14:0], RWL[14:0] (5 V 레벨)          │
            │  기준 워드, 읽기 마스크                │        │ 프리차지·keeper·센스 8열    (VDD)         │
            │                                       │ ◀───── │ 비트라인 드라이버 8열        (VDDW)        │
            └───── R[7:0], VIEW, V_DIR, HALF ───────┘        └──────────────────────────────────────────┘
                       │ (위 채널 11넷)                         디커플링: VDDW 57 pF, VDDA 28.5 pF (MOS)
            ┌──────────▼────────────────────────────┐
 출력 6  ◀─ │ ecc_dec (표준셀, qflow, 조합 논리)     │
            │  표준 복호(SEC/DED), 원시 보기,        │
            │  방향을 아는 복호                      │
            └───────────────────────────────────────┘
```

- 주소 0–14: 맞춤 8T 셀 행. 주소 15: 제어 블록 안의 표준셀 플립플롭 8개(기준 워드). 어레이가 동작하지 않아도 ECC와 결함 주입은 주소 15로 시연된다
- 제어 블록은 읽은 워드 R(저장값 ⊕ 읽기 마스크)까지 만들고, 위 채널 위의 복호 블록 ecc_dec가 R을 판정해 출력 패드를 직접 몬다. ecc_dec에는 플립플롭이 없다
- 셀 크기 18.0 × 27.3 µm(60λ × 91λ, λ = 0.3 µm). 어레이(워드라인 접속, 전원 버스 포함) 170.7 × 414.3 µm, 컬럼 회로까지 붙인 SRAM 매크로 181.5 × 498.3 µm
- 트랜지스터(W/L, µm): PU 1.8/0.6, PD 3.0/0.6, PG 1.8/0.6, 읽기 RD1·RD2 3.0/0.6. 흐름이 그리는 최소는 W 1.8, L 0.6
- 컬럼(열마다, 열 간격 18 µm에 맞춰 그림): 프리차지 P 6.0/0.6, keeper P 1.8/1.8(반 래치), 센스 인버터와 출력 인버터 각각 P 9.0/0.6 N 3.6/0.6, 비트라인 드라이버(VDDW): BLB = not WD, BL = not BLB (각각 P 12.0/0.6 N 6.0/0.6). 인버터는 모두 손가락 2개
- 읽기 포트는 QB가 게이트이므로 RBL은 Q를 따른다(Q = 1이면 RBL이 프리차지 값 그대로). SENSE[7:0]은 Q와 같은 극성
- 전원 셋: VDD(제어 블록, 읽기 회로), VDDA(셀), VDDW(비트라인 드라이버 = 쓸 때 비트라인 높은 값). 평소에는 셋 다 5 V. VDDA와 VDDW는 PANA 패드의 저항 포트(PADR, 약 0.7 kΩ)로 들어오고 칩 안 디커플링이 쓰기 때 전하를 댄다

## 부호와 결함 주입

코드워드 C[7:0] = {D3, D2, D1, P2, D0, P1, P0, PALL}. 신드롬 값이 틀린 비트의 위치다.

```
P0 = D0^D1^D3   P1 = D0^D2^D3   P2 = D1^D2^D3   PALL = D0^D1^D2 (= C[7:1] 전체의 XOR)
```

| FI_MODE | 쓰기(WE = 1), k = FI_POS | 읽기(WE = 0) |
|---|---|---|
| 00 | 부호 그대로 저장 | 정상 읽기, DOUT = 정정한 데이터 |
| 01 | 비트 k 뒤집어 저장(1비트 저장 오류) | 센스 뒤 비트 k 뒤집기(일시 오류), DOUT = 정정 |
| 10 | 비트 k, k^1 뒤집어 저장(2비트) | 센스 뒤 비트 k, k^1, DOUT = 정정 |
| 11 | 비트 k, k^1, k^2 뒤집어 저장(3비트) | 보기(아래 표). FI_POS[2:1]이 고른다 |

| 읽기 FI_MODE 11, FI_POS | 보기 | DOUT | SEC, DED |
|---|---|---|---|
| 000, 001, 100–111 | 원시 보기: FI_POS0 = 1이면 데이터 비트 {R7, R6, R5, R3}, 0이면 검사 비트 {R4, R2, R1, R0} | 저장된 그대로 | 저장 워드의 표준 판정 |
| 011 | 방향 보기, 틀린 비트는 0 → 1만 가정(저전압 읽기·쓰기 실패) | 방향 복호로 고친 데이터 | 아래 부호 |
| 010 | 방향 보기, 1 → 0만 가정 | 방향 복호로 고친 데이터 | 아래 부호 |

SEC = 전체 패리티 불일치, DED = 신드롬 ≠ 0이고 전체 패리티 일치(원시 보기에서도 저장된 그대로의 판정). 원시 보기 두 번으로 저장된 8비트를 모두 읽어 물리 결함이 어느 비트에 났는지 알 수 있다.

방향 보기에서 DIN3 = 1이면 R의 비트 DIN[2:0]을 한 번 더 뒤집는다(일시 오류 1비트). 쓰기 결함 주입(1–3비트 저장 오류)과 합쳐 모든 2비트 패턴과, 쌍 {2m, 2m+1}을 품은 3비트 패턴(56가지 중 24가지)을 논리로 시험할 수 있다. **그래서 방향 보기를 읽을 때는 일부러 뒤집을 때가 아니면 DIN = 0(적어도 DIN3 = 0)으로 둔다.** 쓰기 때의 DIN을 그대로 두면 DIN3 = 1인 패턴(데이터 8–F)에서 R의 한 비트가 뒤집혀 결과가 틀어진다. 다른 읽기 모드에서는 DIN을 보지 않는다.

## 방향을 아는 복호

8T 셀의 저전압 실패는 방향이 정해져 있다. VDDA를 낮춘 채 읽으면 0이 1로만 읽히고(RD1 게이트 QB가 VDDA 수준이라 keeper를 못 이긴다), VDDW를 낮춰 쓰면 1 위에 0을 못 쓴다. 방향 보기는 같은 부호, 같은 저장 비트로 이 사실을 써서 판정한다. U = 틀릴 수 있는 비트(0 → 1이면 R의 1들, 1 → 0이면 R의 0들), S = 신드롬, Q = 전체 패리티.

| 경우 | 판정 | {SEC, DED} |
|---|---|---|
| Q = 0, S = 0 | 오류 없음 | 00 |
| Q = 1, S 자리가 U에 있음 | 그 비트를 고침 | 10 |
| Q = 0, U가 정확히 두 비트(그 둘은 쌍 {i, i⊕S}) | 두 비트를 고침 | 11 (표준 복호에는 없는 조합) |
| 그 밖 | 검출, DOUT은 읽은 데이터 비트 그대로 | 01 |

확장 해밍 (8,4) 부호는 자기 쌍대라 두 부호어가 함께 1인 자리 수가 늘 짝수다. 그래서 한 방향 3비트 오류의 신드롬 자리는 늘 R[S] = 0이고, 표준 복호는 그 멀쩡한 비트를 뒤집어 틀린 값을 SEC와 함께 내지만 방향 보기는 모두 검출한다.

| 틀린 비트 수 (16개 부호어, 한 방향 오류 전부) | 패턴 | 표준 SEC-DED | 방향 보기 |
|---|---|---|---|
| 1 | 64 | 64 고침 | 64 고침 |
| 2 | 112 | 112 검출 | 28 고침(0 → 1이면 데이터 0 워드, 1 → 0이면 데이터 F 워드), 84 검출 |
| 3 | 112 | 112 오정정(틀린 값 + SEC) | 112 검출 |
| 4 | 84 | 56 검출, 28 오정정 | 56 검출, 28 오정정(오류 자체가 부호어) |

방향이 반대인 1비트 오류는 고치지 않고 검출한다. 보존 실패는 셀마다 원래 기우는 값으로 넘어가 양방향이므로 표준 복호로 본다.

## 타이밍

- CLK = 0: 읽기 비트라인 프리차지. ADDR, WE, DIN, FI_*는 이때만 바꾼다
- CLK = 1: 선택된 행 읽기 또는 쓰기. 읽기 출력은 CLK = 1인 동안 유효(CLK = 0이면 프리차지 값 1111이 보인다)
- 비트라인 드라이버는 항상 켜져 있다. 쓰기는 선택된 행의 WWL만 정한다
- 기준 워드는 CLK 상승에서 쓴다
- 측정은 수 kHz–1 MHz면 충분하다. 셀 수준 모의상 읽기 1.2 ns, 쓰기 0.4 ns 이하이고, 칩 코어 전체 모의(패드 코어 쪽 입력 → 복호 블록 → 출력 0.2 pF)는 주기 200 ns에서 CLK = 1 구간이 끝나기 5 ns 전에 모든 출력이 맞았다(접근 시간 자체는 재지 않았다)

## 측정 계획

1. 정상 동작: VDD = VDDA = VDDW = 5 V. 16워드에 서로 다른 값을 쓰고 읽기, 체커보드와 반전
2. 논리 결함 주입: 쓰기 01/10/11, 읽기 01/10. 1비트는 정정되고 SEC, 2비트는 DED, 3비트는 오정정(SEC로 보임)
3. 물리 결함 (원시 보기로 실패 비트 지도를 만들고, 정정 출력과 SEC/DED가 그 지도와 맞는지 본다)
   - 보존: 5 V에서 쓰고 VDDA와 VDDW를 함께 V_hold로 내려 **10 s 이상** 둔 뒤 5 V로 올려 읽기. 0.60 V에서 10 mV씩 내리며 두 패턴(값과 반전)을 모두 본다. 한 패턴으로는 그 셀이 원래 기우는 값과 같은 데이터가 실패로 안 보인다. VDDW를 5 V에 두면 비트라인 누설이 더해진다(별도 실험)
   - 읽기 Vmin: VDDA를 낮춘 채 읽기(VDDW = VDDA). 0으로 저장된 비트가 1로 읽히는 실패가 나온다. keeper와 셀 읽기 전류의 DC 싸움이라 CLK 주기와 거의 무관하다. 모의 TT 1.42 V
   - 쓰기 Vmin: VDDA = 5 V, VDDW를 낮추며 쓰고 5 V에서 읽기. 비트라인을 끌어내리는 드라이버가 약해져 쓰기가 실패한다. 모의 1.73–1.94 V(코너·온도), TT 27 °C 1.86 V
4. 방향 복호 (읽기 Vmin·쓰기 Vmin 실험과 같이)
   - 방향 확인: 원시 보기로 모은 실패 비트가 모두 0 → 1인지 본다. 1 → 0이 섞인 조건에서는 방향 보기 결과를 쓰지 않는다
   - 같은 워드를 정상 읽기(표준 복호), 방향 보기(FI_POS 011), 원시 보기 두 번으로 잇달아 읽고, 쓴 값과 비교해 맞음·검출·오정정(무증상)으로 나눈다. 데이터와 반전 두 패턴, VDDA(= VDDW)를 1–2 mV씩 낮추며. 읽기 때는 DIN = 0
   - 논리 시험(어레이가 죽어도 주소 15로): 데이터 0을 쓰기 모드 10으로 쓰면 정상 읽기는 DED, 방향 보기는 {SEC, DED} = 11과 데이터 0. 쓰기 모드 11(3비트)이면 정상 읽기는 SEC와 틀린 값, 방향 보기는 01. 다른 패턴은 쓰기 모드 01·10에 방향 보기의 DIN 반전을 더해 만든다(2비트는 모두, 3비트는 쌍 {2m, 2m+1}을 품은 것)
5. 어레이가 동작하지 않을 때: 주소 15만으로 2와 4의 논리 시험을 시연한다

# 사양

## 구성

```
            ┌──────────────── VDD 5 V ────────────────┐   ┌──────── VDDA (따로 뺀 핀) ────────┐
 입력 15 ─▶ │ ecc_fi_ctrl (표준셀, qflow)              │   │ 8T 어레이 15행 × 8열              │
            │  부호기, 결함 마스크, 행 해독, 기준 워드  │──▶│  WWL[14:0], RWL[14:0] (5 V 레벨)  │
 출력 10 ◀─ │  신드롬, 정정, SEC/DED                   │   │ 쓰기 드라이버 8열 (VDDA 전원)     │
            │                                          │◀──│ 프리차지·keeper·센스 8열 (VDD)    │
            └──────────────────────────────────────────┘   └───────────────────────────────────┘
```

- 주소 0–14: 맞춤 8T 셀 행. 주소 15: 제어 블록 안의 표준셀 플립플롭 8개(기준 워드). 어레이가 동작하지 않아도 ECC와 결함 주입은 주소 15로 시연된다
- 셀 크기 18.0 × 27.3 µm(60λ × 91λ, λ = 0.3 µm). 어레이(워드라인 접속, 전원 버스 포함) 170.7 × 414.3 µm, 컬럼 회로까지 붙인 SRAM 매크로 176.1 × 498.3 µm
- 트랜지스터(W/L, µm): PU 1.8/0.6, PD 3.0/0.6, PG 1.8/0.6, 읽기 RD1·RD2 3.0/0.6. 흐름이 그리는 최소는 W 1.8, L 0.6
- 컬럼(열마다, 열 간격 18 µm에 맞춰 그림): 프리차지 P 6.0/0.6, keeper P 1.8/1.8(반 래치), 센스 인버터와 출력 인버터 각각 P 9.0/0.6 N 3.6/0.6, 쓰기 드라이버(VDDA): BLB = not WD, BL = not BLB (각각 P 12.0/0.6 N 6.0/0.6). 인버터는 모두 손가락 2개
- 읽기 포트는 QB가 게이트이므로 RBL은 Q를 따른다(Q = 1이면 RBL이 프리차지 값 그대로). SENSE[7:0]은 Q와 같은 극성
- 매크로 핀: 왼쪽 WWL0–14, RWL0–14(metal3), PRE_N(metal1). 아래쪽 SENSE0–7, WD0–7(metal2, 열마다 x 3.9–5.1 µm, 8.1–9.3 µm), VSS·VDDA·VDD 버스(metal2)

## 부호와 결함 주입

코드워드 C[7:0] = {D3, D2, D1, P2, D0, P1, P0, PALL}. 신드롬 값이 틀린 비트의 위치다.

```
P0 = D0^D1^D3   P1 = D0^D2^D3   P2 = D1^D2^D3   PALL = D0^D1^D2 (= C[7:1] 전체의 XOR)
```

| FI_MODE | 쓰기(WE = 1), k = FI_POS | 읽기(WE = 0) |
|---|---|---|
| 00 | 부호 그대로 저장 | 정상 읽기, 정정 |
| 01 | 비트 k 뒤집어 저장(1비트 저장 오류) | 센스 뒤 비트 k 뒤집기(일시 오류) |
| 10 | 비트 k, k^1 뒤집어 저장(2비트) | 센스 뒤 비트 k, k^1 |
| 11 | 비트 k, k^1, k^2 뒤집어 저장(3비트) | 원시 보기: DOUT_RAW = 데이터 비트, DOUT_CORR = {R4, R2, R1, R0} |

SEC_FLAG = 전체 패리티 불일치, DED_FLAG = 신드롬 ≠ 0이고 전체 패리티 일치. 원시 보기(읽기 11)로 저장된 8비트를 모두 볼 수 있어 물리 결함이 어느 비트에 났는지 알 수 있다.

## 타이밍

- CLK = 0: 읽기 비트라인 프리차지. ADDR, WE, DIN, FI_*는 이때만 바꾼다
- CLK = 1: 선택된 행 읽기 또는 쓰기. 읽기 출력은 CLK = 1인 동안 유효(CLK = 0이면 프리차지 값 1111이 보인다)
- 쓰기 드라이버는 항상 켜져 있다. 쓰기는 선택된 행의 WWL만 정한다
- 기준 워드는 CLK 상승에서 쓴다
- 측정은 수 kHz–1 MHz면 충분하다(모의상 읽기 1.2 ns, 쓰기 0.4 ns 이하)

## 핀 배치(안, MPW_PAD_28pin)

| 핀 | 신호 | 핀 | 신호 |
|---|---|---|---|
| 1 | CLK | 15 | FI_POS1 |
| 2 | WE | 16 | FI_POS0 |
| 3–6 | ADDR3–ADDR0 | 17 | VSS (PVSS) |
| 7 | VDD (PVDD) | 18 | SEC_FLAG |
| 8–11 | DIN3–DIN0 | 19 | DED_FLAG |
| 12–13 | FI_MODE1–0 | 20–23 | DOUT_CORR3–0 |
| 14 | FI_POS2 | 24 | DOUT_RAW3 |
| | | 25 | VDDA (PANA PADR) |
| | | 26–28 | DOUT_RAW2–0 |

입력 PIC 15개, 출력 POB4 10개, 전원 3개. 측정 중 입력을 띄워 두지 않는다(GPIO 비고). VDDA는 아날로그 패드로 받고 칩 안에 디커플링(약 100 pF)을 둔다. VDDA N-well과 VDD N-well은 4.0 µm 이상 띄운다.

## 측정 계획

1. 정상 동작: VDD = VDDA = 5 V. 16워드에 서로 다른 값을 쓰고 읽기, 체커보드와 반전
2. 논리 결함 주입: 쓰기 01/10/11, 읽기 01/10. 1비트는 정정되고 SEC, 2비트는 DED, 3비트는 오정정(SEC로 보임)
3. 물리 결함
   - 보존: 5 V에서 쓰고 VDDA를 V_hold로 내려 **10 s 이상** 둔 뒤 5 V로 올려 읽기. 0.60 V에서 10 mV씩 내리며 두 패턴(값과 반전)을 모두 본다. 한 패턴으로는 그 셀이 원래 기우는 값과 같은 데이터가 실패로 안 보인다
   - 읽기 Vmin: VDDA를 낮춘 채 읽기. 0으로 저장된 비트가 1로 읽히는 실패가 나온다. keeper와 셀 읽기 전류의 DC 싸움이라 CLK 주기와 거의 무관하다
   - 원시 보기로 실패 비트 지도를 만들고, 정정 출력과 SEC/DED가 그 지도와 맞는지 본다
4. 어레이가 동작하지 않을 때: 주소 15만으로 2를 시연한다
